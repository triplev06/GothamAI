GROQ STREAMING FORMAT
=====================

From Groq API:
data: {"choices":[{"delta":{"content":"text"}}]}

Expected by Frontend:
data: {"content":"text"}

Transformation needed:
- Extract choices[0].delta.content from Groq chunks
- Wrap in { content: ... } format
- Keep "data: " prefix
- Add [DONE] at end
